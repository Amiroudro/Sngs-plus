# Sarangsho Plus

Bilingual (Bengali-first) daily newspaper + exam-learning platform for Bangladeshi BCS/Bank job candidates. One repo holds the whole project so any collaborator — human or AI — can read it, edit it, and propose changes.

## Layout

- `app/` — the Flutter app (Sarangsho Plus, v1.2.1, build 2013, package `com.sarangsho.plus`). Bengali-first: editions, vocab cards, quizzes, SRS revision, self-update from GitHub. Start with `app/README.md` and `app/BUILD_NOTES.md`.
- `engine-v2/` — the LIVE daily engine (Python, standard library only). Collects from 15 Level 1 newspapers, ranks, summarises, generates the daily edition, and publishes it when the 15-check gate passes. First v2 edition: Edition 11, 17 Nov 2026. Start with `engine-v2/PLAN.md`, `engine-v2/CONTRACTS.md`, `engine-v2/CRON_INSTRUCTIONS_V2.md`, `engine-v2/SOURCES.md`.
- `engine-v1/` — the FROZEN v1 engine. It produced Editions 1–10 and the 7/7 proof (see `engine-v1/tracker.md`). Read it for history only; do not run it.
- `frontend/` + `backend/` — the Astro web build. Deployment notes: `docs/INTEGRATION_STATUS.md`.
- `editions/` — published edition JSON archive (English editions + Bangla overlays).
- Public editions feed (what the app downloads): https://github.com/Amiroudro/sarangsho-plus-editions

## How editions flow

engine-v2 (08:00 Asia/Dhaka) → 15-check gate → publish → public editions repo → app downloads + self-updates. Auto-publish rule (Rudro, 2026-11-15): every v2 edition from Edition 11 onward auto-publishes on gate 15/15.

## What is NOT in this repo (by design)

- Release keystore + `keystore.properties` — NEVER commit. They live only with the app owner; losing them means the app can never be updated on Play Store again.
- Build outputs (`app/build/`), Gradle caches, `.dart_tool/` — regenerated by `flutter build`.
- Binary assets: the 3 Bengali fonts (`app/assets/fonts/*.ttf` — Hind Siliguri Regular/Bold, Noto Serif Bengali Bold; free Google Fonts), the Android launcher PNGs, `gradle-wrapper.jar`. Restore them from the app's release machine, or download the fonts from Google Fonts. The app will not build without the fonts.
- `app/assets/editions/bn-*.json` + `index.json` in this repo are the web-renovated copies — their story text was edited for the web build, so do not overwrite them with the Flutter app's shipped overlays. The English `data-*.json` files here are the app's bundled copies; the shipped Bengali overlays live in the public editions repo.
- Daily run data (`engine-v2/runs/`, v1 runs) — outputs, not code.
